# Spike: the terminal's permission options (ALY-288)

Method: a real interactive Claude Code 2.1.314 session in a throwaway folder (its own `git init`, outside every repository), on a private tmux socket, with a capture hook from a kit that is not committed. The prompts were driven with send-keys and fixed, harmless commands. Deviation approved by Bruno: the run used the machine's existing login and no dedicated `CLAUDE_CONFIG_DIR`, with `--setting-sources project,local --strict-mcp-config`, so the main run never read or wrote the real user settings file. A follow-up session (ALY-288.4) loaded user settings with the plugins disabled, backed the real file up, exercised `userSettings` once and restored it byte-identical (S05, S22). Every line below is observed; a line that was not observed says "not produced" or "not observed" and is never guessed (BR-01). No path, command, rule text or credential is committed (BR-03); fixtures are in `hooks/fixtures/live/spike-options-*.json`, scrubbed per AC-04.

Reading the lines: "entry classes" are `addDirectories`, `addRules` (with its destination), `setMode`. "reproduced" means the hook output tried (`allow` with `updatedPermissions`) closed the open dialog and had the effect of the terminal option; "not reproduced" says why. Dialog options are numbered as the terminal shows them.

## Conclusion

Verdict reasons. update=go: reproduced, with a hook output tried on the tool: `addDirectories` (session), `addRules` (session, localSettings, projectSettings, userSettings; compound Bash with 2 rules; Read outside, WebFetch, WebSearch, Skill with 2 entries, MCP stub), `setMode` (acceptEdits on Bash, subagent Bash, Write, Edit, NotebookEdit; auto from default and from acceptEdits on Bash), the `addDirectories` plus `setMode` pair in one output, and the AskUserQuestion answer by `updatedInput`. NOT reproduced (tried), so ALY-290 must not offer them: the protected-path `.claude` option 2 (T12) and the ExitPlanMode answer (T20). Not reproduced (not tried): the T03 option 2 rule `git init *` in acceptEdits (class proven on Bash default); T19 option 2 (not tried on the stub named plugin_allye_allye; identical shape to T18, replayed on the stub named stubmcp). Not produced: T02 (same payload as T01), T04, T08, T09, T23, T24, T25, T26, T27; T05 shows no dialog (auto-classifier). Non-Bash tools inside acceptEdits were not tried beyond the rows above.

auto=go: proven on Bash prompts in `default` (T01, T28, S07) and in `acceptEdits` (T03, hook setMode auto reproduced it), constant-based (tool plus mode) with no payload field that proves the terminal shows it. Point for Bruno to confirm: T05 and T27 (already in auto) were not tried and T25 to T27 were not produced. late=safe: S09, S16, S17 and S18 showed no effect beyond what a terminal answer allows. beat=none: S10 and S11, inferred from the dialog offering Yes.
